# Solystra Jewels &bull; Luxury E-Commerce Web Application

A flagship luxury fine jewelry e-commerce experience built with **React**, **Vite**, and **Tailwind CSS**. Crafted with a bespoke luxury design system featuring Royal Burgundy (`#7A152E`), Champagne Gold (`#C5A059`), and Warm Alabaster (`#FAF8F5`).

---

## ✨ Features

- **Full E-Commerce Catalog & Atelier**: Pure 925 Sterling Silver, 18K Gold Vermeil, Rings, Necklaces, Bracelets, Earrings, and Curated Gift Sets.
- **Dynamic Category & Collection Sliders**: Infinite fluid dragging & auto-cycling category pods with pure CSS micro-animations.
- **Interactive Video Reels Carousel**: Solystra video showcase with instant modal preview and quick Add-to-Cart / Buy-Now workflows.
- **Product Detail Page (PDP)**:
  - High-resolution multi-angle gallery with interactive lightbox.
  - Ring size guide with diameter conversion and visual ruler.
  - Bespoke complimentary gift privilege card with auto-applied BOGO reward and white light shine beam animation.
  - 4-pillar hallmarked assurance guarantee badges.
  - Delivery pincode estimation with real-time feedback.
- **End-to-End Shopping Flow**:
  - Flyout slide cart drawer with automatic free shipping threshold indicator.
  - Verified discount promo codes (`SILVER10`, `SILVER15`, `SILVER20`, `SOLYSTRA25`, `BOGOFREE`).
  - Streamlined luxury checkout modal with multi-step payment methods (UPI, Cards, Net Banking, COD).
  - Celebration success confirmation screen with animated SVG checkmark and golden halo.
- **Responsive Architecture**: Pixel-perfect layout optimization across mobile, tablet, laptop, and ultra-wide displays.
- **Deploy Ready**: Self-contained Netlify production build with static SPA redirects and asset packaging.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Installation
```bash
# Clone the repository
git clone https://github.com/Vrundpatel153/solystra.git

# Navigate into project directory
cd solystra

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
The application will launch locally at `http://localhost:5173`.

### Production Build
```bash
npm run build
```
This runs the prebuild task, compiles the minified Vite bundle, synchronizes production assets, and outputs a self-contained `/dist` directory with `dist/_redirects` and `dist/netlify.toml`.
